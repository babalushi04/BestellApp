## 🛒 ORDERING APP PROJECT

A modern, accessible **restaurant ordering web application**.

The Ordering App is the **5th project** of my Frontend Developer training.

---

## 🔧 Technologies

- **HTML5** – Semantic structure using `<dialog>`, `<header>`, `<main>`, `<footer>`, `<section>`
- **CSS3** – Custom properties, Flexbox/Grid, responsive design
- **JavaScript**
- **Raleway Font** – Locally embedded font
